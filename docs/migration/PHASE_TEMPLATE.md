# Шаблон файла фазы

Файл фазы — самодостаточный work order для модели-исполнителя (Sonnet). Генерируется сильной моделью (Fable/Opus) в начале фазы, когда известны результаты предыдущих. Не писать файлы будущих фаз заранее: они устаревают.

Правила составления:
- Задача = 0.5–2 часа работы исполнителя. Крупнее — дробить.
- Каждая задача указывает: какие Python-файлы/функции ПРОЧИТАТЬ (спецификация), какие Swift-файлы создать/изменить, критерий приёмки с конкретной командой или действием.
- Не пересказывать логику Python-кода прозой, если исполнитель может её прочитать. Пересказывать только то, что размазано по нескольким файлам или неочевидно (инварианты, гонки, причины).
- Секции «Вне scope» и «Инварианты» обязательны.
