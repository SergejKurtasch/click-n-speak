# Sanitized UI References

This directory is reserved for the signed-app screenshots captured by the Epoch 10 manual matrix. Do not include transcripts, API keys, usernames, file paths, or other personal data.

Naming convention:

`<surface>-<locale>-<aqua|dark>-<1x|2x>[-<state>].png`

Required surfaces are listed in `docs/swift_implementation_epochs/EPOCH_08_UI_PARITY_INVENTORY.md`. Intentional differences from the Python reference must be documented here before cutover; no difference is currently approved by omission.
